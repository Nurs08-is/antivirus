# Демо-антивирус (оқу мақсатында)

Сигнатуралық және эвристикалық талдауды көрсететін шағын Python бағдарламасы.

## Іске қосу
    py antivirus_app.py

## Файлдар
- scanner.py — негізгі код
- signatures.json — белгілі зиянды файлдардың SHA-256 хэштері
- test_files/ — қауіпсіз тест файлдары

Бағдарлама тек файлдарды оқиды, ештеңені өзгертпейді немесе жоймайды.
